# brainstorming

নিজের career plan নিয়ে প্রশ্ন-উত্তরের markdown — চাকরি বদল, DSA, system design, সঞ্চয়, ৪০-এর পরিকল্পনা। কোড নয়। ১১টা বিষয়ের ফাইল; প্রতিটার ভেতরের প্রতিটা সেকশন একটা প্রশ্নের উত্তর, আর সব মিলে একটাই পরিকল্পনা।

Repo: https://github.com/sojibrd/brainstorming

## Functional Requirement

- **প্রশ্ন ধরে উত্তর:** কোনো career প্রশ্নে ("লোকাল না রিমোট?", "কয়টা প্রজেক্ট লাগবে?", "৪০-এ কত টাকা?") বিষয়ের ফাইল খুলে সেই সেকশন।
- **পুরো পরিকল্পনার মানচিত্র:** [`thought-map.md`](thought-map.md) দেখায় কোন সেকশন কোন ধারণার অংশ (Mermaid mindmap, ৮টা শাখা), শাখা পেরোনো যোগসূত্র, আর লেখাগুলোর মধ্যে অমিলের রেকর্ড।
- **নিচের প্রজেক্টগুলোর উৎস:** ১৮০ দিনের তিন plan (`switch_in_6_month_local_company`, `_remote_company`, `_global_company`) আর DSA, system design, behavioural-এর তিন পথের সাইট এখান থেকে তথ্য নেয়।

## Non-Functional Requirement

- **কোনো অনুমান নয়।** যা ফাইলে বা ব্যবহারকারীর উত্তরে নেই তা লেখা হয় না — জিজ্ঞেস করা হয়, একবারে একটা প্রশ্ন, সাথে সুপারিশ।
- **সব md ফাইলে একই তথ্য,** [`ASSUMPTIONS.md`](ASSUMPTIONS.md)-এর সাথেও — ওটাই সত্যের একমাত্র উৎস।
- **অমিল পেলে নিজে ঠিক করা নয়** — `thought-map.md`-এর "অমিল" সেকশনে লিখে ব্যবহারকারীকে জিজ্ঞেস।
- **এই repo-র জন্য কোনো টুল, সাইট বা script নয়।** এখানকার ফাইলগুলো নিজেই সতর্ক করে: "এবারের কাজ বানানো নয়, পাঠানো।"
- **এক বিষয় = এক ফাইল; নামে নম্বর নেই, নাম বদলায় না** — বাইরের repo এই নামগুলোয় লিংক করে।

## প্রজেক্ট-নির্দিষ্ট নিয়ম

- **নতুন লেখা এলে:** আগে কোনো বিষয়ের ফাইলে `##` সেকশন হিসেবে merge, ব্যবহারকারীর হ্যাঁ-র পরে; কোনো বিষয়ে না মিললে তবেই নতুন ফাইল, নম্বর ছাড়া নাম। সেশন শুরুতে এজেন্ট স্ক্যান করে `thought-map.md` হালনাগাদ করে — নিয়ম [`AGENTS.md`](AGENTS.md)-এ।
- **স্ক্যানে বাদ:** `thought-map.md`, `ASSUMPTIONS.md`, `AGENTS.md`, `CLAUDE.md`, `README.md` আর `docs/plans/`।
- **নতুন ফাইল যোগ হলে এই README-র "বিষয়" টেবিলেও** career plan-এর ক্রমে সারি যোগ করুন।
- **ফাইলের নাম বদলাবেন না:** `dsa_prep_*`, `system_design_*`, `behavioural_interview_*` আর তিন switch plan-এর `AGENTS.md`, `README.md` ও `docs/` এই নামগুলোয় লিংক করে; বদলাতেই হলে ঐ সব জায়গা একসাথে।
- **তথ্য বদলানোর ক্রম:** [`ASSUMPTIONS.md`](ASSUMPTIONS.md) → এখানকার সংশ্লিষ্ট সব ফাইল একসাথে → নিচের প্রজেক্ট।
